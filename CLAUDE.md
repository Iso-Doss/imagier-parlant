# Directives du projet Imagier parlant

## Langue

**Tout est en français, toujours** : réponses, documentation, textes d'interface, messages
d'erreur visibles, messages de commit, descriptions de pull request.
Seul le code reste en anglais (noms de variables, fonctions, classes, routes, colonnes).

dans le même commit que le code.
